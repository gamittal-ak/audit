What do these labels mean?

sTLS and eTLS identify the configured delivery network. Shared cert means Akamai's built-in shared certificate (PAPI cnameType SHARED_CERT, shown as "Shared" in Property Manager). Each property is counted once per category in the selected network; mixed configs can appear in multiple categories. These are configuration snapshots, not traffic measurements.

A TLS network or CPS-managed provisioning alone does not prove a deployed certificate. HTTP-only means either Property Manager lists the hostname as "No certificate (HTTP Only)" (an Akamai-owned *.akamaized.net name without the shared certificate), or no matching certificate or enrollment was found in a completely collected accessible CPS inventory for a custom hostname on the standard network. This is limited to the API client’s visibility; it is not inferred from failed probes or the legacy secure flag. Check HTTPS availability in the row details; unresolved cases remain Unknown. Older reports need a new audit to collect this evidence.
